# SQL Practice
 
Repositório dedicado aos meus estudos de SQL Server utilizando o banco AdventureWorks.
 
O objetivo deste projeto é desenvolver conhecimentos em consultas SQL aplicadas à análise de dados, explorando desde consultas básicas até agregações e relacionamentos entre tabelas.
 
## Estrutura
 
### EX001
Conceitos praticados:
- SELECT
- WHERE
- COUNT
- DISTINCT
- INNER JOIN
- GROUP BY
 
### EX002
Conceitos praticados:
- TOP
- ORDER BY
- IS NULL / IS NOT NULL
- COUNT
- AVG
- GROUP BY
- Análise de produtos
- Métricas por categoria
 
## Tecnologias
 
- SQL Server
- SSMS
