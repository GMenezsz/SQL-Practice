# 📚 Estudos de SQL

Repositório criado para registrar minha evolução em SQL utilizando o banco de dados AdventureWorks.

## Conteúdos estudados

- SELECT
- WHERE
- ORDER BY
- INNER JOIN
- GROUP BY
- COUNT()
- MAX()
- MIN()
- AVG()

## Exercícios realizados

- Consulta de pessoas e funcionários
- Relacionamento entre tabelas com INNER JOIN
- Contagem de funcionários por cargo
- Ranking de vendedores por vendas anuais
- Estatísticas de vendas utilizando funções de agregação

## Aprendizados

- Como relacionar tabelas através de chaves
- Funcionamento do GROUP BY e COUNT
- Diferença entre a ordem escrita e a ordem de execução do SQL
- Uso de aliases com AS
- Aplicação de MAX, MIN e AVG
- Filtragem de dados com WHERE
