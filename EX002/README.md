# 📚  SQL Studies - AdventureWorks
 
Estudos de SQL Server utilizando o banco AdventureWorks.
 
## Conceitos praticados
 
- SELECT
- WHERE
- COUNT
- DISTINCT
- TOP
- ORDER BY
- GROUP BY
- AVG
- INNER JOIN
 
## Exercícios
 
- Produtos por faixa de preço
- Tratamento de valores NULL
- Contagem e agregações
- Agrupamentos por cor e categoria
- Preço médio por grupo
- Produtos mais caros e mais baratos
 
## Tecnologias
 
- SQL Server
- SSMS
- AdventureWorks
