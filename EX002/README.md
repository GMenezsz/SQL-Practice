# Prática de Consultas SQL (AdventureWorks)
 
Repositório contendo scripts e consultas SQL desenvolvidos para prática de manipulação, filtragem, agregação e cruzamento de dados relacionais.
 
## Conceitos praticados
 
- SELECT
- WHERE
- COUNT
- DISTINCT
- TOP
- ORDER BY
- GROUP BY
- AVG
- INNER JOIN
 
## Exercícios
 
- Produtos por faixa de preço
- Tratamento de valores NULL
- Contagem e agregações
- Agrupamentos por cor e categoria
- Preço médio por grupo
- Produtos mais caros e mais baratos
 
## Tecnologias
 
- SQL Server
- SSMS
- AdventureWorks
